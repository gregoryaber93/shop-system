# UI UX Accessibility Rules

- Build a modern, bold interface while preserving a consistent product aesthetic.
- Design mobile-first and test breakpoints.
- Ensure semantic HTML and keyboard accessibility.
- Add aria-* attributes only where native semantics are not enough.
- Control contrast, focus rings, and content readability.
- Use animations sparingly and intentionally (entry, state change, action confirmation).

## Components

- Base components should support disabled, loading, and error states.
- Forms: inline validation, clear feedback, and recovery guidance.
- Text and labels should be unambiguous and task-oriented.
