# UI UX Accessibility Rules

- Tworz nowoczesny, wyrazisty interfejs, ale zachowuj spojna estetyke w calym produkcie.
- Projektuj mobile-first i testuj punkty przelamania.
- Zapewnij semantyczny HTML i dostepnosc klawiaturowa.
- Dodawaj aria-* tylko tam, gdzie semantyka natywna nie wystarcza.
- Kontroluj kontrast, focus ring i czytelnosc tresci.
- Animacje stosuj oszczednie i celowo (wejscie, zmiana stanu, potwierdzenie akcji).

## Komponenty

- Komponenty bazowe powinny wspierac disabled, loading i error.
- Formularze: walidacja inline, czytelny komunikat i podpowiedz naprawy.
- Teksty i etykiety maja byc jednoznaczne i zorientowane na zadanie uzytkownika.
